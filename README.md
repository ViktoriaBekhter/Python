# Python
Кейсы Python

В кейсах были выполнены следующие задачи:
1. Реализовала статистические операции и анализировала данные с использованием
библиотек Python (pandas, numpy)
2. Строила различные статистические модели, включая расчет выбросов, дисперсии,
межквартильного размаха, моды и базовых статистик на Python.
3. Проводила нализ данных (EDA), а также базовый разведывательный анализ данных
(Exploratory Data Analysis, EDA) с использованием библиотек Python (matplotlib.pyplot, pandas,
numpy и seaborn).
4. Работала с данными в формате JSON, включая их парсинг и манипуляцию.
5. Написала программу, которая выполняет пользовательские команды на основе хранимых
данных
